Résumé
  1. Un clone neuf pouvait ne pas démarrer le serveur : le réglage de mvnw (backend/.mvn/wrapper) était ignoré par git. Il est maintenant dans le dépôt.
  2. Une installation npm faite par erreur à la racine (package.json, node_modules/claude) est retirée, et ne peut plus y revenir.
  3. Restes retirés du dépôt : l'ancienne maquette front.html et les 24 captures de scratch/screens (gardées sur le disque, scratch/ étant déjà ignoré).
  4. Un README à la racine dit ce que contient le dépôt et comment le lancer et le tester.
  5. backend/libero-shop.png : vérifié, il n'est plus ni dans git ni sur le disque ; rien à faire.

1. Ce qui a été fait

Figure 1 — Ce qui entre et ce qui sort du dépôt.

Les règles d'exclusion empêchent le retour des fichiers retirés : /node_modules/, /package.json et /package-lock.json sont ignorés à la racine (l'interface garde les siens dans ui/). La ligne /.mvn/ de backend/.gitignore, qui cachait le réglage de mvnw, est retirée ; le binaire maven-wrapper.jar reste ignoré, mvnw sait s'en passer.

2. Ce qui a été laissé

ui/src/app/release/ contient un APK de 28 Mo construit le 10 octobre. Il n'est pas dans le dépôt (les .apk sont ignorés) ; c'est peut-être la version distribuée aux téléphones. Il est laissé sur le disque : à déplacer hors du code source (par exemple dans downloads/) quand vous le jugerez bon.
