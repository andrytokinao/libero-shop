Index sur les dates : les écrans restent rapides avec les années

17 octobre 2026 · branche develop · point « Index manquants » de docs/TODO.md (§ 5, P3)

Résumé
  1. Les ventes du jour, les factures d'un mois, les paiements du jour, l'historique d'un produit : tout se lit par date.
  2. Ces quatre colonnes de date n'avaient pas d'index : la base parcourait toute la table, ce qui ralentit avec les années.
  3. Une migration de démarrage crée les quatre index s'ils manquent, sur toute installation, ancienne ou neuve. Rien d'autre ne change.

  • 2. Tableau récapitulatif

1. Ce qui a été fait

Figure 1 — Un index sur la date permet de lire un jour sans parcourir toute l'histoire.

La migration (DateIndexMigration) s'exécute à chaque démarrage et ne crée que ce qui manque : un second démarrage ne fait rien. Une table absente (installation incomplète) est simplement passée, sans bloquer le démarrage.
