  2. « Voir les écarts » résume avant d'écrire : produits comptés, écarts (en quantité et en ariary), produits conformes, produits laissés vides.

1. Le problème

Pour inventorier un rayon de vingt produits, il fallait ouvrir vingt fois « Compter ce produit », sans vue d'ensemble des écarts avant de les enregistrer.

2. Ce qui a été fait

Figure 1 — Compter, relire les écarts, enregistrer : rien n'est écrit avant l'étape 3.

Côté serveur, POST /api/stock/inventories reçoit les produits comptés. Chaque produit trouvé différent passe par la même règle qu'un comptage seul (« Inventaire »), dans une seule transaction : si un produit est refusé (supprimé entre-temps, compté deux fois), aucune correction n'est écrite et le comptage reste à l'écran. Les produits trouvés conformes ne créent aucune ligne d'historique. La valeur des écarts est donnée au prix de vente, pour mesurer l'importance d'un écart avant de valider.
