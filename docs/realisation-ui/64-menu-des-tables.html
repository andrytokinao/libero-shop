UI-71« ⋮ » des tables et QR codes

17 octobre 2026 · branche develop · point UI-71 de docs/todo-ui.md

Résumé
  1. Les trois boutons sous chaque QR code deviennent un « ⋮ » : Renommer, Copier le lien, Imprimer ce QR code, Nouveau code, Supprimer.
  2. Renommer est nouveau (côté serveur aussi) : le QR code imprimé reste valable, seul le nom change.
  3. Imprimer ce QR code imprime une seule table, au lieu de toutes.
  4. « Nouveau code » et « Supprimer » passent par la fenêtre de confirmation commune, qui dit la conséquence.
  5. Corrigé au passage : un clic dans la fenêtre « Renommer » était annulé par le fond de la fenêtre.

1. Ce qui a été fait

Figure 1 — Ce qui garde le QR code imprimé se fait d'un geste ; ce qui l'invalide demande confirmation.

Côté serveur, PUT /api/tables/{id} change le nom d'une table et garde son code ; un nom déjà porté par une autre table est refusé (sa propre orthographe en majuscules ne l'est pas). Les commandes passées gardent l'ancien nom, les suivantes portent le nouveau.

Corrigé : sur cette page, la fenêtre « Renommer » fermait au clic sur son fond par une expression qui renvoyait « faux » pour tout autre clic ; Angular annule alors le clic, et le bouton « Renommer » ou la touche Entrée n'envoyaient rien. C'est le même piège que celui déjà noté pour les touches de la caisse ; aucune autre fenêtre de l'application ne l'utilise.

3. À éviter / attendu

À éviter
(click)="$event.target === $event.currentTarget && close()"

renvoie « faux » pour tout clic dans la fenêtre : le clic est annulé.

Attendu
(click)="onBackdrop($event)"   // méthode qui ne renvoie rien
