UI-21Code-barres inconnu à la vente

16 octobre 2026 · branche develop · point UI-21 de docs/todo-ui.md

Résumé
  1. À la caisse et à la prise de commande, un code-barres que aucun produit ne porte ouvre une fenêtre « Code inconnu », au lieu d'un simple message.
  2. Tout le monde peut y chercher l'article par son nom et l'ajouter au panier : la vente continue.
  3. Qui peut modifier le catalogue (responsable de dépôt, administrateur) peut aussi associer le code au produit, en choisissant l'unité sur laquelle il est imprimé (la pièce, le carton…).
  4. Ou bien créer le produit avec le code déjà rempli.
  5. Une fois associé, le code est relu tout seul : l'article arrive dans le panier, dans la bonne unité. Le scan suivant le trouve directement.

1. Le problème

Un client apporte un article dont le code-barres n'est pas encore dans le logiciel : nouvel arrivage, carton d'un autre fournisseur. Avant, la caisse affichait « code inconnu » et s'arrêtait là. Le caissier devait chercher l'article à la main dans les tuiles. Le code restait inconnu, donc le problème revenait au scan suivant.

2. Ce qui a été fait

Le champ « Rechercher ou scanner » passe maintenant le code inconnu à l'écran, qui ouvre la fenêtre « Code inconnu ». Ce que la fenêtre propose dépend du rôle :

Figure 1 — Le code inconnu n'est plus une impasse : chercher, associer ou créer.

Associer un code ne passe pas par une nouvelle route du serveur. On réutilise les mêmes écritures que la fenêtre de configuration : la fiche du produit pour l'unité de base, l'unité elle-même pour un carton. Tout le reste du produit (nom, prix, contenance, prix d'achat) reste tel quel. Si le code appartient déjà à un autre article, le serveur refuse et le message le dit.

4. À éviter / attendu

À éviter
// Associer le code en réécrivant la fiche
// avec ce que l'écran croit savoir :
updateProduct(id, { ...ligneDuPanier, barcode })
Attendu
// Relire le produit, ne changer que le code,
// garder le prix d'achat tel que les réceptions l'ont fait :
productUnits(id) → updateProduct(id, { ...fiche, barcode, purchaseCost: null })
