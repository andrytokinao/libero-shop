UI-21Code-barres inconnu à la vente

16 octobre 2026 · branche develop · point UI-21 de docs/todo-ui.md

Résumé
  1. Un code-barres qu'aucun produit ne porte n'est plus une impasse : une fenêtre « Code inconnu » s'ouvre à la caisse et à la prise de commande.
  2. Le caissier cherche l'article par son nom et le met dans le panier ; le code reste de côté.
  3. Qui peut modifier le catalogue choisit le produit puis l'unité (pièce, carton…) qui porte ce code : le code lui est associé et l'article est ajouté.
  4. Il peut aussi créer le produit : la fiche s'ouvre avec le code déjà rempli.
  5. Le serveur refuse un code déjà porté par un autre produit ; le message dit lequel.

1. Le problème

Quand la douchette lisait un code inconnu, la caisse affichait seulement « Code inconnu ». Le caissier devait effacer, retrouver l'article à la main dans la grille, et le code restait inconnu pour la vente suivante. Pour l'enregistrer, il fallait quitter la vente, aller dans Prix et unités et ouvrir la configuration du produit.

2. Ce qui a été fait

Le code inconnu est maintenant gardé par la saisie de la vente, qui ouvre une fenêtre. Ce que propose la fenêtre dépend du droit de modifier le catalogue (le même droit que pour le menu « ⋮ » du produit).

Figure 1 — Après un code inconnu : le chemin du caissier en haut, celui de qui gère le catalogue en dessous.

Une fois le code associé ou le produit créé, la caisse relit le code comme si on venait de le scanner : l'article entre dans le panier dans la bonne unité (un carton si le code est celui du carton). Associer un code ne touche à rien d'autre du produit : ni le prix, ni le prix d'achat, ni le contenu du carton.

Avant
« Code inconnu » s'affiche ; le caissier efface et cherche dans la grille ; le code reste inconnu.
Maintenant
Une fenêtre propose de chercher l'article par son nom, de lui donner ce code ou de créer le produit.

4. Ce qui reste à décider

« Code inconnu à la caisse : prévenir le responsable de dépôt ? » est une décision attendue de docs/todo-ui.md. Rien n'est envoyé pour l'instant : le caissier vend l'article, le code reste inconnu.
Une unité ne porte qu'un code : associer un nouveau code remplace l'ancien (Figure 6, « remplace 6001001000015 »). Les paquets encore en rayon avec l'ancien code deviennent inconnus. Signalé dans docs/todo-ui.md comme décision attendue (plusieurs codes par unité : changement côté serveur).
