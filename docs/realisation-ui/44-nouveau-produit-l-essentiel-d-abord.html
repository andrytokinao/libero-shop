UI-12UI-91Nouveau produit : l'essentiel d'abord

17 octobre 2026 · branche develop · points UI-12 et UI-91 de docs/todo-ui.md

Résumé
  1. « Nouveau produit » ne montre d'abord que le nom, le prix et l'unité ; catégorie, code-barres, prix d'achat et stock de départ sont repliés sous « Plus de détails ».
  2. Tant que « Créer le produit » est grisé, une phrase dit ce qui manque (« Il manque : un prix de vente »).
  3. Après la création, le message propose la suite : « Ajouter du stock » et « Codes-barres », d'un clic.
  4. Le champ Code-barres a la même largeur que les autres.
  5. Les messages de l'application peuvent maintenant porter des boutons : UI-83 (« Annuler ») s'en servira.

1. Le problème

La fenêtre montrait huit champs, alors que trois suffisent. Le bouton restait grisé sans dire pourquoi. Une fois le produit créé, il fallait le retrouver dans la liste pour lui ajouter du stock ou un code.

2. Ce qui a été fait

Figure 1 — L'essentiel d'abord, puis la suite proposée dans le message.

« Plus de détails » s'ouvre tout seul quand quelque chose y est déjà rempli : un code scanné inconnu (UI-21) ou une copie de produit (UI-02). « Ajouter du stock » n'est proposé qu'au responsable de dépôt, comme dans le menu.
