1. Le contournement

Sur un poste de développement, les réglages du projet doivent pouvoir couper la licence : c'est ainsi que les tests tournent sans fichier de licence. Le garde reconnaissait ce poste au dossier d'où le programme est lancé. Ce dossier, n'importe qui peut le créer avec le bon nom.

2. Ce qui a été fait

Figure 1 — Les deux conditions doivent être réunies pour suivre les réglages du projet.

Le brouillage des noms se fait à la construction du logiciel livré, et il ne touche pas aux textes du programme. Le garde compare donc son propre nom à son nom d'origine, écrit en toutes lettres : en développement ils sont égaux, dans le logiciel livré ils diffèrent. Pour remettre les noms d'origine, il faudrait reconstruire le logiciel, ce qui est justement la limite que le garde veut imposer.
